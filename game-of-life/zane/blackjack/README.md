# Blackjack GUI

Palaiž ar:

```powershell
python game.py
```

Spēlē:
- tu spēlē pret dīleri ar savu žetonu banku;
- `ZanesBlackjack` uzņemas otro bota roku pie galda;
- tiek izmantotas 4 kāršu kavas;
- kurpe tiek samaisīta pēc aptuveni 75% izspēles;
- dīleris stāv uz soft 17;
- blackjack maksā 3:2;
- pieejamas likmes, HIT, STAND, DOUBLE un SPLIT darbības.
